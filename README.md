# harryrobertshaw.github.io

Personal academic website for Harry Robertshaw, built with Jekyll and the same AcademicPages/Minimal 

## Editing content

- Homepage and standalone pages: `_pages/`
- Publications: `_publications/`
- Masthead navigation: `_data/navigation.yml`
- Author profile and site settings: `_config.yml`
- Images and downloadable assets: `assets/` and `images/`

GitHub Pages builds the site automatically after changes are pushed to the publishing branch.
